# Данные владельца

Скопируйте эту папку командой `b2b-agent init`. Она создаёт только отсутствующие файлы и сохраняет ваши изменения. Реальные клиентские материалы, цены и INPUT исключайте из Git. Не помещайте сюда OAuth, пароли, токены и ключи.

В `services.json` перечислены декларации возможностей. У каждой услуги стабильный `id` и `workflow`, точные `supported_tasks` и `unsupported_tasks`, ограничения, необходимые данные, участие клиента, доступность команды и разрешённый первый шаг. Добавлять услугу можно без изменения Python. Поддержка всего внедрения CRM не следует из наличия сценария приёма заявок. Не заменяйте неизвестную цену нулём: в `price` оставьте `minimum`, `maximum` и `currency` равными `null`, а в `dependencies` укажите условия расчёта. Для известного числа обязательна валюта. `allowed_claims` требуют `source`: декларация возможности не является подтверждённым клиентским результатом.

В `proof_assets.json` храните только настоящие материалы. `type=client_case` означает клиентский кейс; `team_experience` — личный опыт участника; `demo` и `prototype` — тестовый пример. Их нельзя выдавать друг за друга. Пустой массив означает, что доступные подтверждения неизвестны (`public_case_status=unknown`). Только владелец может указать `none_confirmed`, добавив основание в `status_source`. Разрешённые для отправки материалы требуют `availability=available`, явных `publication_allowed`/`attachment_allowed` и проверенной доступности. Файл сам по себе не даёт права рассказывать его содержание. Ограничения NDA указывайте только для реально существующего материала. Локальный `path` должен оставаться внутри INPUT; `../`, абсолютный путь за пределы INPUT и такие же симлинки запрещены. Не помещайте код в JSON.

В `sender_profile.json` укажите реальный бренд/человека, фактическую роль, `from_email`, утверждённую подпись и владельца встречи. Не придумывайте сотрудников, опыт или логотипы клиентов. Отправка невозможна без отдельно настроенных credentials, проверки правил контакта и разрешения каждого сообщения.

Проверка: `b2b-agent validate-input --input INPUT`. Перечитывание: `b2b-agent reload-catalog --input INPUT`. Сохраняйте JSON атомарно (временный файл и переименование). Ошибка или незавершённая правка блокирует зависимые действия; старая цена не используется молча. Изменение услуги, связанных материалов или подписи требует обновить разрешение соответствующего сообщения. Архивные snapshots содержат версию данных решения; не редактируйте их вручную.
