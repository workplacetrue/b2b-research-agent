# Проверка MVP — 29 октября 2026

Среда: Python 3.12.14, Crawl4AI 0.8.9; зависимости зафиксированы в uv.lock.

## Выполнено

- `uv sync --frozen --extra dev`: успешно.
- `pytest -q`: **20 passed**, без skipped/xfail. Покрыты канонизация и отклонение небезопасных URL, CSV, факты и цитаты, буквальные контакты, отсутствие гипотез при отсутствии доказательств, валидный/невалидный LLM JSON и отсутствующий ключ, Brave API через mock, дедупликация повторных запусков, частичные ошибки, SQLite/JSON/CSV, formula injection, robots.txt (запрет, недоступность, wildcard), приватный DNS, запрет редиректов, сжатые HTTP-ответы. Интеграционный тест использует настоящий Crawl4AI с фиктивным HTTP-ответом на русском языке.
- `ruff check src tests`: успешно.
- Настоящий сетевой pipeline через штатный egress-прокси, повторён после финальных изменений:

```bash
uv run b2b-agent run --config examples/config.json \
  --csv examples/smoke-sites.csv --db output/smoke.sqlite --output output/smoke
```

Результат: `{"companies": 2, "ok": 2, "partial": 0, "failed": 0}`. PyPI: 1 страница; RubyGems: 2 страницы. robots.txt получен для обоих сайтов. SQLite и два экспорта созданы, повторный запуск не добавил компаний-дублей. Нишевые сигналы и контакты отсутствуют, оценки равны нулю, черновики не созданы — технические сайты не выдаются за целевых клиентов.

## Заблокировано / не запускалось

- `www.komus-upakovka.ru` и `pack24.ru`: CONNECT через egress-прокси возвращает 403 Domain forbidden. Это запрет среды до обращения к сайту, не вывод о состоянии сайтов или robots.txt. Качество на реальных компаниях выбранной ниши ещё не проверено. В `examples/sites.csv` только кандидаты для следующего запуска.
- Прямой DNS из облачной среды недоступен; использован явный `dns_mode=proxy` с доверенным штатным HTTPS_PROXY. Вне этой среды рекомендуется local.
- Реальные Brave/LLM API не вызывались: переменные BRAVE_API_KEY и B2B_LLM_API_KEY отсутствуют. Адаптеры проверены mock-ответами, это не подтверждает доступ к коммерческим API.
- Сначала была попытка установки Chromium, заблокированная доменной политикой. Финальная реализация не требует браузера и не использует никаких артефактов этой попытки.

Сохранены черновики install_script, start_skill и разрешений доменов поставщиков и API. Сохранение не применяет сетевую политику и не публикует среду. Для проверки ниши сохраните соответствующие настройки среды и повторите запуск; API требуют безопасно заданных ключей. Не отправляйте их в чат.
